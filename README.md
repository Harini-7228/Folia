# Folia: plants & home decor
A responsive multi-page static website built for the ApexPlanet web development internship (Tasks 1 to 5). Built with HTML5, CSS3 and vanilla JavaScript only.

**Live demo:** _add your Netlify/Vercel link here_ | **Demo video:** _add your YouTube link here_

## Features
- Home, About, Services and Contact pages with a shared header and footer
- Product cards with quick-view modal, wishlist and cart (saved in localStorage, no checkout)
- Enquiry form with real-time validation (name, email, phone)
- Promo slider, animated counters, dark/light mode, back-to-top, mobile menu, smooth scrolling
- Plant care by weather (OpenWeatherMap API) and plant care reminders (todo list with filters)

## Tech stack
HTML5, CSS3 (Flexbox, Grid, CSS variables, BEM), JavaScript ES modules, OpenWeatherMap API, localStorage.

## Run locally
ES modules need a server, so open the folder in VS Code and use **Live Server** (double-clicking the HTML file will not run the JavaScript).
1. Get a free key at openweathermap.org and paste it in `js/config.js`.
2. Click "Go Live".

## Project structure
`css/` one file per section or page, `js/` modules (ui, cart, api, utils, weather, todo), `assets/images/` for photos, `docs/` for the submission guide.
